## 🧬 О проекте

Цель проекта — исследование производительности различных алгоритмов поиска наиболее часто встречающихся подпоследовательностей в последовательностях ДНК на широком спектре вычислительных архитектур: классических CPU (x86 с AVX-512), RISC-V с векторным расширением RVV 1.0, GPU NVIDIA A100.

Бенчмарк позволяет сравнивать:
- последовательные и параллельные реализации;
- скалярные и векторные версии;
- CPU- и GPU-реализации;
- различные модели параллелизма (OpenMP, Kokkos, CUDA, SYCL, Coarray Fortran).

## 🚀 Поддерживаемые архитектуры и технологии

| Категория | Поддержка |

## 🧮 Алгоритмы

В репозитории представлены следующие алгоритмы:

- **Naive** — наивный поиск методом бегущего окна
- **Rabin–Karp** — алгоритм Рабина–Карпа с полиномиальной хеш-функцией или хеш-функцией SWAR в двух вариантах
- **Hash3** — быстрый алгоритм поиска подстроки в строке для алфавитов малой мощности ([Lecroq 2007](https://www.sciencedirect.com/science/article/pii/S0020019007000117?casa_token=gLV8RuvKlR8AAAAA:8kWt_rwGiq2nRYwg7SBk1i52SpKeNZv8RSneZhTxMNk7_xdHh5arsuGcQknzW4PP7spjc9jn))

## 🛠 Сборка

Для сборки под Unix-подобные системы запустите следующую команду:

```bash
./build.sh -p <platform> -f <framework>
```

Зависимости и программное окружение:

- CMake ≥ 4.1
- GCC/Clang с поддержкой C++17 (С++20 для Kokkos 5.1.1)
- SYCL-совместимый компилятор (Intel oneAPI DPC++ 2023.0.0 или 2025.1.1)
- OpenMP
- Kokkos (версии 4.7.04 для x86 и NVIDIA GPU, 5.1.1 для RISC-V)
- CUDA 11.3 (для сборки под NVIDIA GPU)
- Компилятор Fortran с поддержкой Coarray (Intel ifx (IFORT) 2023.0.0)
